1 Résumé exécutif

L'équipe de développement a reçu le dossier fonctionnel IA-Ready version 1.1 (statut : À valider, daté du 2025-01-23) et a produit l'intégralité du code source de la solution POC.

Le code couvre les 5 capacités fonctionnelles définies dans le dossier (C-001 à C-005), respecte les 5 règles transversales (RT-001 à RT-005), les 5 paramètres système (PARAM_001 à PARAM_005) et les 6 messages utilisateur (MSG-001, 002, 004–007).

État général Le code est complet et prêt à être installé et testé. La prochaine étape est l'exécution de npm install && npm run dev pour validation visuelle dans le navigateur.
3 écarts mineurs identifiés Trois points du dossier fonctionnel ne sont pas encore implémentés (CA-005 liste résultats Nominatim, MSG-006 fond de carte indisponible, User-Agent Nominatim). Ils sont documentés en section 9.

3.3 Flux de données

Le flux est unidirectionnel, conforme à l'architecture React :

  1. Démarrage : batiments.json est importé statiquement dans App.jsx via dataLoader.js. Les données sont en mémoire instantanément.
  2. Saisie adresse : SearchBar remonte l'adresse à App.jsx, qui appelle geoEngine.geocoderAdresse(). Le résultat est stocké dans l'état pointIntervention.
  3. Calcul rayon : Dès que pointIntervention change, useMemo recalcule batimentsDansRayon via geoEngine.filtrerParRayon().
  4. Filtrage : Un second useMemo applique les filtres C-004 sur batimentsDansRayon → produit batimentsFiltres.
  5. Affichage : MapView reçoit batimentsFiltres et rend les markers. Au clic marker → BuildingSheet reçoit le bâtiment sélectionné.
